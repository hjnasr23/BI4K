# Supabase Database Documentation

## New Table: `Mockup`
This table was created to store categorized clothing mockups.

| Column | Type | Description |
| --- | --- | --- |
| `id` | UUID | Primary Key (autogenerated) |
| `name` | TEXT | Original filename |
| `url` | TEXT | Public URL from Supabase Storage |
| `cloth_type` | TEXT | Category: t-shirt, hoodie, mug, etc. |
| `target_audience` | TEXT | Category: men, kids, women |
| `view` | TEXT | Category: front, back |
| `created_at` | TIMESTAMPTZ | Creation timestamp |
